# Implementation Roadmap

## Phase 1
- Repo structure and architecture docs.
- Docker dev stack.
- Go backend bootstrap with clean layers.
- Next.js frontend bootstrap with modern dashboard shell.

## Phase 2
- Auth domain, user model, login/refresh/logout.
- Admin bootstrap user flow.
- Quota model and enforcement service skeleton.

## Phase 3
- File/folder schema and repositories.
- Upload/download/chunk APIs.
- Local storage provider integration.

## Phase 4
- File manager UI (tree, list/grid, bulk actions).

## Phase 5
- Preview worker pipeline (image/pdf/video).

## Phase 6
- Version history and trash restore/purge.

## Phase 7
- Secure sharing links with policies.

## Phase 8
- 2FA and audit log UI/API hardening.

## Phase 9
- WebDAV adapter and compatibility validation.

## Phase 10
- Sync APIs and desktop/mobile client readiness.

## Phase 11
- Plugin framework and initial extension hooks.

## Phase 12
- Debian production deployment docs, systemd units, reverse proxy configs, custom ports.
